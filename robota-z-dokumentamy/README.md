# Робота з документами

Проєкт для створення повідомлень, будь-яких документів та обробки різних матеріалів.

## Структура

| Папка | Призначення |
|-------|-------------|
| `povidomlennya/` | Повідомлення (листи, меседжі, пости, email) |
| `dokumenty/` | Готові документи (звіти, договори, заяви, інструкції) |
| `shablony/` | Шаблони для повторного використання |
| `obrobka/` | Вхідні матеріали та результати обробки (конвертація, редагування, зведення) |
| `arkhiv/` | Завершені та застарілі файли |

## Як користуватись

Просто опишіть, що потрібно: створити повідомлення, скласти документ, опрацювати файл — і результат буде збережено у відповідній папці.
